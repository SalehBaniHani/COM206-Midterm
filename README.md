## 📱 Project Description
This project is a Flutter mobile application designed to provide a clean and simple shopping experience.

Users can:
- Login
- Browse clothing models
- Check size guide
- Reserve or buy items
- View orders

---

## 🎨 UI Design
The design is inspired by Figma and focuses on:

- Soft colors

## 🎯 Problem Statement & Solution

### 🔴 Problem
Many clothing shopping experiences are confusing and not user-friendly.  
Users often face issues such as:
- Difficulty choosing the correct size  
- Unclear product presentation  
- Complicated navigation between pages  
- Lack of simple and clean design  

---

### ✅ Solution
The Gülşah app was designed to solve these problems by providing:

- ✔ A clear and simple user interface  
- ✔ Easy navigation between screens  
- ✔ A dedicated size guide to help users choose correctly  
- ✔ Organized product display (Model 1, Model 2, Model 3)  
- ✔ Smooth checkout process (Reserve / Buy)  

---

### 💡 Result
The application improves the user experience by making shopping:
- Easier  
- Faster  
- More organized
